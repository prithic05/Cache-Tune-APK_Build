# 📱 CacheTune Android APK

This directory contains the latest pre-compiled build of **CacheTune**.

## 🚀 Quick Install on Android Phone

### Method 1: Direct Transfer
1. Copy `CacheTune.apk` to your Android device via USB cable, Google Drive, or local file sharing.
2. Open the file on your device and tap **Install** (allow *Install from Unknown Sources* if prompted).

### Method 2: ADB Install
Connect your phone with **USB Debugging** enabled and run:
```bash
adb install -r CacheTune.apk
```
